# 스포츠 도슨트 — 주제별 스포츠 교육 콘텐츠

Instagram [@sports_docent](https://www.instagram.com/sports_docent/)의 스포츠 교육 카드뉴스 14편을 주제별 웹 아티클로 정리한 정적 사이트입니다.

- **자료 제작** : 대구 스포츠컨텐츠연구회
- **페이지 제작** : 대구 AI체육수업실천연구회

## 구성

- `index.html` — 메인 (14개 주제 카드 그리드)
- `01_감독복장/` ~ `14_부카츠/` — 주제별 페이지(각 폴더 `index.html`) + 카드뉴스 이미지
- `style.css` — 전 페이지 공통 스타일
- `gallery.js` — 카드뉴스 캐러셀 + 라이트박스

# 학생 의견 → 구글 시트 연결 설정 방법

의견 페이지(`의견나누기/index.html`)에서 제출한 학생 의견을 구글 시트에 자동으로 쌓으려면,
아래 순서대로 **한 번만** 설정하면 됩니다. (약 5분 소요)

---

## 1단계 · 구글 시트 만들기

1. [sheets.new](https://sheets.new) 로 새 스프레드시트를 만듭니다.
2. 이름을 예: `스포츠 도슨트 - 학생 의견` 으로 정합니다.
   (시트 탭 이름은 건드리지 않아도 됩니다. 스크립트가 `의견` 시트를 자동으로 만듭니다.)

## 2단계 · Apps Script 붙여넣기

1. 그 시트에서 상단 메뉴 **확장 프로그램 → Apps Script** 를 클릭합니다.
2. 편집기에 있던 기본 코드(`function myFunction() {}`)를 **모두 지웁니다.**
3. 같은 폴더의 **`apps-script.gs`** 파일 내용을 **전부 복사해 붙여넣습니다.**
4. 💾 저장(Ctrl+S)합니다.

## 3단계 · 웹앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포** 를 클릭합니다.
2. 톱니바퀴(유형 선택) → **웹 앱** 을 선택합니다.
3. 아래와 같이 설정합니다.
   - **설명**: `학생 의견 수집` (아무거나)
   - **다음 사용자로 실행**: **나** (본인 계정)
   - **액세스 권한이 있는 사용자**: **모든 사용자**  ← ⚠️ 반드시 이 값이어야 학생이 제출할 수 있습니다.
4. **배포**를 누르고, 권한 승인을 진행합니다.
   - "이 앱은 확인되지 않았습니다" 경고가 나오면 → **고급** → **(프로젝트 이름)(으)로 이동** → **허용**
5. 발급된 **웹 앱 URL** 을 복사합니다.
   `https://script.google.com/macros/s/AKfycb....../exec` 형태입니다.

## 4단계 · 사이트에 URL 붙여넣기

`의견나누기/index.html` 파일을 열고, 아래 부분을 찾아 따옴표 안에 URL을 붙여넣습니다.

```js
var SHEET_ENDPOINT = "";
```
↓
```js
var SHEET_ENDPOINT = "https://script.google.com/macros/s/AKfycb....../exec";
```

저장 후 커밋·푸시하면 끝입니다.

---

## 확인 방법

- 의견 페이지에서 직접 한 번 제출해 보세요.
- 시트에 `제출시각 / 학번 / 이름 / 주제 / 의견 / 수업소감` 6개 열로 행이 추가되면 성공입니다.

## 참고 사항

- **코드를 수정한 뒤에는** Apps Script에서 **배포 → 배포 관리 → (연필 아이콘) → 버전: 새 버전 → 배포**를
  해야 변경 내용이 반영됩니다. 이때 URL은 그대로 유지됩니다.
- 이 저장소는 공개되어 있으므로, 웹앱 URL을 아는 사람은 누구나 데이터를 보낼 수 있습니다.
  수업 중에만 사용하고, 학기가 끝나면 **배포 관리 → 보관처리**로 비활성화하는 것을 권장합니다.
- 스팸이 들어오면 시트에서 해당 행을 삭제하면 됩니다.
